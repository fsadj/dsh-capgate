# 架构：词法收缩 + 语义闸门 + 独立审查 agent + 策略兜底

> 当前版本（v0.2.0 交付版）。完整伪代码见仓库根目录 `架构伪代码.md`。

## 一句话

**把"要不要放行"从一次模型判断，换成一次带调查的判断。**

- 词法只保留三件事：拦绝对危险、降调用开销、留审计；
- 判定主责交给一个独立的、只能读的审查 agent；
- 策略只把它的结论映射成动作，并守住两条不由模型决定的底线。

## 分层

```
工具调用
  ↓
① 词法层（词法收缩）
     绝对危险 10 条（命中即拒）
     命令形状缓存（同形状只编译一次，可落盘）
     种子只读规则 10 条（整条精确匹配；含管道/重定向即不命中）
     审计
  ↓
② 语义闸门
     词法说"读"时，放行前要语义也同意
     shadow：只记录词法与语义是否一致（量错误率）
     on    ：语义不同意就不放行（fail-closed）
  ↓
③ 独立审查 agent（subagent）
     自己的上下文（主 agent 转录进不来）
     只读工具：read / glob / grep（写、发、执行物理不可达）
     结构化输出：
        verdict      allow | deny | ask
        dataClass    none | code | business | personal | credential
        blast        { estimate, reversible }
        consistency  match | mismatch
        clear        [{lock, quote}]               解除锁必须带引文
        alternatives [{label, op, scope}]          最小替代
  ↓
④ 任务状态（派生）
     指令（逐字，带 msgId）/ 已批准 / 已拒绝 / 进度 / 关系
     不落盘、不让模型维护文档；读的时候现算
  ↓
⑤ 策略（只做映射与兜底）
     deny / 凭据 / 不一致          → 拒绝（带 alternatives）
     allow 且无硬锁且影响面可接受  → 放行
     其他                         → 四段式询问
  ↓
⑥ 人（唯一能批准锁死类别）
```

## 判定顺序（与源码同序）

| # | 步骤 | 结果 |
|---|---|---|
| 0 | 绝对危险（10 条） | DENY |
| 1 | 敏感路径（凭据） | DENY / ASK |
| 2 | 同签名 · 已确认范围 · 来源事实 | ALLOW |
| 3 | 读闸门（语义确认） | ALLOW |
| 4 | 引文（逐字）/ 语义引文 | ALLOW |
| 5 | 锁（batch/egress/opaque/privilege） | 交给审查 agent |
| 6 | 审查 agent（只读调查） | ALLOW / DENY / ASK |
| 7 | 策略映射 + 兜底 | DENY / ASK |
| 8 | 四段式询问 | ASK |

## 四条放行依据

1. 可证明只读（含种子规则与语义确认）；
2. 用户原话逐字引文（span 校验）；
3. 已确认范围 / 来源事实（人批过的类、本任务自建文件）；
4. 审查 agent 判 allow，且过策略。

## 两条不由模型决定的底线

- **凭据类永不进对话**：纯 agent 在"用户明确要求"时会放行，所以必须留在代码里；
- **效果不可知时必须问**：这不是意图问题，是事实缺失。

## 不变量

```
自动放行 ⇒ 可证明只读 ∨ 引文覆盖 ∨ 已确认范围 ∨ 来源事实
不可证明 ⇒ ASK 或 DENY
任何组件只能收紧：模型、规则、审查 agent 都不能让判定更松
授权只来自用户原话；派生视图（任务状态 / 缓存 / 契约）不可扩权
```

## 成本与延迟

| 手段 | 效果 |
|---|---|
| 种子只读规则（10 条） | 常见只读命令 0 次模型调用 |
| 命令形状缓存（可落盘） | 同形状第二次 0 次 |
| 判定缓存（可落盘） | 重复调用 0 次子 agent |
| 并发去重 | 同一判定只起一个子 agent |
| `reviewerModel` | 可换更小的模型 |
| 重试 + 超时翻倍 | 真机失败率 30% → 0 |
